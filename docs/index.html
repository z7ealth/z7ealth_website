About

I've spent 10+ years across enterprise Linux, Kubernetes, VMware and software engineering. Today I design hybrid cloud platforms on OpenShift, lead VMware-to-Kubernetes migrations (120+ VMs into OpenShift Virtualization so far), and run Linux operations for critical production infrastructure.

I'm usually the escalation point when something deep in the stack breaks, working alongside Red Hat TAMs, architects and support engineering. Sometimes that means reading upstream source and shipping a patched controller image before the official fix lands.

Before infrastructure I was a software engineer, and I still write a lot of code: lately a terminal emulator and a Material Design library for Phoenix.
